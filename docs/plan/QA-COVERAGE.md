## Driver capabilities (QA-0)

- Per-page capture of **console errors/warnings, pageerror, requestfailed**, attributed to the surface.
- **Assertions** on outcomes (state updated, element appeared, value applied).
- **Unhappy-path injection** via `installMock({ failMethods: [...] })` so error handling is exercised.
- Exits non-zero on any FAIL (console error / pageerror / requestfailed / failed assertion).
