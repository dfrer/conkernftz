## @foundry/storage

Storage providers for the conkernftz foundry.

Providers
- Arweave via Bundlr (`uploadFileViaBundlr`)
- IPFS via NFT.Storage (`uploadViaNftStorage`) and Pinata (`uploadViaPinata`)

Configure via `foundry.config.json` under `storage`.

See `docs/CLI_REFERENCE.md` for `foundry upload` usage.
