## @conkernftz/chain-solana

Solana chain adapter for the conkernftz foundry.

Capabilities
- Build off-chain metadata JSON compatible with Token Metadata
- Mint via Umi/Token Metadata (devnet/testnet/mainnet-beta)

Configuration lives in `foundry.config.json` under `chain.solana`.

See `docs/CLI_REFERENCE.md` for `foundry mint` usage.
