## @conkernftz/ui (Electron)

Electron-based GUI for the conkernftz foundry.

Start
```
pnpm -C packages/ui build
pnpm -C packages/ui start
```

Notes
- On first run, the app ensures the CLI is built. If missing, it shows exact steps to fix.
- Both `preload.ts` and `preload.cjs` exist for compatibility.

Documentation
- See `docs/UI_GUIDE.md` for features and limitations.
